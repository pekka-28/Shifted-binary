# Foundry Shifted binary

Start with [Shifted binary reader guide – Foundry](Shifted-binary-reader-guide.md) for the XML problem, representation and display. The same guide is available as HTML and PDF alongside the Markdown file in the distribution.

- [Installing shifted binary – Foundry](Installing-shifted-binary.md) covers the fonts, registry files and editor settings.
- [Using shifted binary in XSLT – Foundry](Using-shifted-binary-in-XSLT.md) presents the complete SBE-to-FIXML transformation case study, including its message, field interpretation, output and process diagram.
- [Binary XML converters – Foundry](../examples/Using-the-converters.md) explains the supplied TypeScript and C# source programs.
- *Convenient binary XML encoding* is optional deeper reading on Unicode and the type specification, supplied in PDF and Word editions listed in the distribution's contents.

The reader, installation and Using guides are supplied as Markdown, HTML, PDF and editable Word documents, with embedded diagrams in the distribution. The Using guide is the case study. Its linked archive contains the full generator and unchanged reference implementation; the supplied backgrounder and superseded source editions are not included.

Open this distribution's folder as a VS Code workspace to use its Markdown font settings. Install the Fallback font as described in the installation guide to display shifted values while editing.
